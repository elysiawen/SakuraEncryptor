# Sakura Encryptor 🌸

**Sakura Encryptor** (原 SKV-Shield) 是一套完整的 **零知识（Zero-Knowledge）** 隐私保护方案，专门用于个人云端媒体文件的极速加密与跨设备无感播放。

通过这套系统，你可以将私密的视频、音频和图片文件加密后存储在 AList、OpenList 或任何 WebDAV 服务上，并在浏览器、安卓设备或桌面应用上实现流畅的实时解密播放，而无需担心服务器泄露你的数据或密码。

## ✨ 核心特性

- **🛡️ 纯前端零知识架构**：密码永远不离本地，解密过程 100% 在浏览器内完成，服务端仅作为静态代理。
- **⚡ 极速实时流解密**：基于 Service Worker 和 Web Crypto API，支持视频任意跳进度（Seek），即点即播。
- **🎵 沉浸式音乐体验**：专属黑胶唱片播放界面，支持动态环境光效及 ID3 专辑封面自动提取。
- **🖼️ 图片浏览**：支持常见图片格式的实时解密查看，可旋转、缩放与前后翻页；图集还能切到「条漫」连续阅读，滚动时工具栏自动隐藏。
- **📋 播放列表**：音乐、视频、图片播放页均支持文件夹内同类型文件的播放列表，可快速切换、自动播放下一首。
- **📊 实时性能监控**：在播放页集成 FPS、丢帧率、解密延迟、网速及缓存命中率的实时监控。
- **💾 智能离线缓存**：Service Worker 2.0 级块缓存（LRU），显著降低网络流量消耗，解决流量放大问题。
- **🧩 双云端后端**：云端配置可建 AList 或 OpenList（AList 的社区分支，`/api` 协议一致，三端都能选）；OpenList 还支持分片上传，超大加密文件不会卡在单次请求体积上限。
- **🏠 安卓内置服务器**：`openlist` 变体把 OpenList 编进应用进程，在 `127.0.0.1` 上提供完整文件服务，数据落在应用私有目录 —— 不接任何外部服务器也能用目录树、缩略图与在线播放，前台通知保证进程不被冻结。
- **📱 安卓客户端**：Kotlin + Jetpack Compose 原生应用，支持本地文件加解密、AList / OpenList 云端目录浏览，以及边下边解密的流式播放；解密缓存可关，锁定即清空。
- **🖥️ 桌面客户端**：Electron + Vue 3，把云端库、本地库、加密工作台与传输队列放进同一个窗口；本地库用一套独立密码直接读取磁盘，无需上传；两个文件库都支持多选模式批量下载与删除，并带启动锁、托盘与 `.ske` 文件关联。
- **🔐 应用启动锁**：启动时可要求启动密码，并可叠加 TOTP 令牌与指纹 / 面容；勾选的验证方式按「全部通过」或「任一通过」组合，先通过的方式会被记住，验证顺序随你。TOTP 密钥以 Android Keystore 密封保存，绑定前必须用验证器当场生成的验证码确认。
- **🗂️ 缓存管理**：缩略图缓存、解密媒体块缓存与派生密钥记忆可分别开关，前两者还能设定容量上限，超限按最久未用淘汰。
- **🔒 工业级加密**：采用 AES-256-GCM 认证加密与 PBKDF2 (100,000 迭代) 密钥导出。

## 📦 项目结构

- **`ske_cli/`**：Python 编写的桌面客户端。负责本地文件的极速加密。
- **`ske_web/`**：Vue 3 + Service Worker 驱动的在线播放站。负责云端文件的实时流解密播放。
- **`ske_desktop/`**：Electron + Vue 3 桌面客户端。云端库、本地库、加密工作台与传输队列合一，自带启动锁与托盘。
- **`ske_android/`**：Kotlin + Jetpack Compose 安卓客户端。支持本地加解密、AList / OpenList 云端浏览与流式解密播放；`openlist-lib/` 用 gomobile 把 OpenList 编译成 AAR，供「内置服务器」使用。
- **`ske_extension/`**：Chrome 扩展（Sakura Encryptor 跨域小助手）。为指定网盘的跨域响应补上 `Access-Control-Allow-Origin`，让 Web 端能直接读取不支持 CORS 的网盘。
- **`tests/`**：完善的加密一致性测试脚本。

## 🚀 快速开始

### 1. 本地加密 (CLI)

确保已安装 Python 3.10+。

```bash
pip install .          # 安装后提供 ske / ske-gui 命令

# 加密单个文件或整个目录
ske encrypt -i "my_video.mp4" -o ./encrypted -p "your-password"
ske encrypt -i ./videos -o ./encrypted -p "your-password" -r   # -r 将源文件夹名一并纳入加密树

# 解密还原
ske decrypt -i ./encrypted -o ./restored -p "your-password"
```

也可以用 `python -m ske_cli ...` 调用；图形界面（支持拖拽）运行 `ske-gui`。

### 2. 在线播放 (Web)

确保已安装 Node.js。

```bash
cd ske_web
npm install
npm run dev
```

1.  打开浏览器访问 `http://localhost:5173`。
2.  选择「AList 云端」或「OpenList 云端」，输入服务器地址、账号与密码（启用两步验证时会再要一次验证码）。
3.  点击加密文件，输入加密时设置的密码。
4.  开始享受私密播放！

> 只想看本机文件时切到「本地」标签，选一个文件夹即可在浏览器内解密播放，不需要上传到任何服务器。

> Web 端由 Service Worker 直接向网盘发起跨域请求来解密，因此网盘直链必须允许 CORS。遇到不放开跨域的网盘（浏览器只会报 `Failed to fetch`），界面会提示具体原因，并把该域名推给浏览器扩展 `ske_extension/`（Sakura Encryptor 跨域小助手）；装上扩展并添加该域名后刷新即可正常解密，未安装扩展时可改用桌面 / 安卓客户端浏览该网盘。

### 3. 桌面客户端 (Desktop)

需要 Node.js 18+ 与 npm。

```bash
cd ske_desktop
npm install
npm run dev      # 开发模式：Vite + Electron，改前端代码即时生效
npm run build    # 生产构建，输出到仓库根目录 out/renderer
npm start        # 运行已构建的应用
```

应用启动后无需任何账号，四个页面覆盖全部工作流：

- **云端库**：先在「云端配置」中新建一套 AList / OpenList 账号与独立加密密码，再回「云端库」浏览、播放与上传。
- **本地库**：选一次目录并用**本地密码**解锁，之后直接读写磁盘上的 `.ske` 与普通文件；本地密码与云端配置互不相干。
- **加密工作台**：把本地文件或整个文件夹加密到目标目录，任务队列实时显示进度。
- **传输**：下载解密、上传加密都在后台队列里跑（默认 2 并发）。开启「关闭窗口时留在托盘」后，关窗不会中断进度。

两个文件库都支持**多选模式**：点工具栏「多选」后，点击条目即勾选（按住 `Shift` 可连选一段），顶部操作条提供全选、取消选择、批量下载与批量删除；再点「完成」或按 `Esc` 退出。右键已选条目同样可以批量操作。

「设置」里可以开启**启动锁**（密码、TOTP，或两者按「全部通过 / 任一通过」组合；TOTP 密钥由系统密钥库密封），控制缩略图缓存（落盘的是加密预览，可设容量上限）、播放步长、下载目录以及窗口 / 托盘行为。`.ske` 文件会关联到桌面端，双击即可在应用内播放。

### 4. 安卓客户端 (Android)

需要 Android SDK（compileSdk 35）与 JDK 17+。

```bash
cd ske_android
./gradlew assemblePlainDebug      # 普通版，不含内置服务器
# 产物：app/build/outputs/apk/plain/debug/app-plain-debug.apk

./gradlew assembleOpenlistDebug   # 带内置 OpenList
# 产物：app/build/outputs/apk/openlist/debug/app-openlist-debug.apk
```

`assembleDebug` 会一次构建两个 flavor。`openlist` 变体依赖 `app/libs/openlistlib.aar`（28 MB，不入库），文件缺失时构建直接报错；需要时用 `ske_android/openlist-lib/build.ps1` 重新生成，该脚本要求 Go、gomobile、Android SDK 与 NDK，默认只编 `android/arm64`，要给模拟器用加 `-Targets "android/arm64,android/amd64"`。

应用启动后**直接进入主界面，不需要任何账号**：

- **只用本地**：在「本地」页输入一次**本地密码**，即可播放 / 加解密本地 `.ske` 文件，并选择文件夹加密新文件。本地密码与云端配置完全独立。
- **需要云端**：在「设置 → 云端配置」中新建配置 —— **每个配置 = 一套 AList / OpenList 账号 + 一套独立的加密密码**。可以保存多个配置并随时切换，切换后自动解锁并重连。
- **不想有服务器**：`openlist` 变体的「设置 → 内置服务器」可在手机里直接跑一个 OpenList，文件存在应用私有目录；打开开关会自动建好并切到「内置服务器」配置，加密密码仍照常在浏览页输入，「管理内置存储」里可以添加存储、调整挂载路径或删除挂载（删挂载不动文件）。

所有密码都只以 Android Keystore 加密的形式落盘（可在配置中勾选“记住”），解密时仅存在于内存。

安卓端提供四大功能：云端加密目录浏览与播放、本地 `.ske` 文件播放、本地文件加解密、下载并解密到本地。云端目录按 500 条一页自动翻完，超过 AList 默认 200 条的文件夹不会被截断；条目在解密后按自然序排列（文件夹优先）。

「设置 → 安全」可开启**启动锁**：设置启动密码后，可勾选密码、TOTP 令牌、指纹 / 面容任意组合，并在同一页绑定身份验证器（密钥只以 Keystore 密封形式保存）。「设置 → 缓存」可分别控制缩略图、解密媒体块与派生密钥记忆，并设定前两者的容量上限。

## 🛡️ 技术原理


### 加密逻辑（SKE 版本 001）
1.  **文件分块**：每个文件被切分为 1MB 的块。
2.  **密钥导出**：利用用户密码 + 随机 Salt，通过 PBKDF2-HMAC-SHA256 (100k 迭代) 导出 256 位 Master Key。
3.  **分块加密**：每个块独立使用 AES-256-GCM 加密，并带有独立的 Nonce；AAD 由「Magic / 版本 / Salt / Master IV」前缀与紧随其后的 22 字节选项块（`KEY_CHECK`、KDF 迭代次数、FLAGS）拼接而成，任何一处被改动都会直接认证失败。
4.  **实时解密**：Service Worker 拦截 `/ske-decrypt/` 请求，按需拉取加密分块并在内存中完成解密，随后通过 `Content-Range` 响应喂给播放器。
5.  **加密预览**：图片与视频都可携带一枚 512px 的 AES-GCM 加密 JPEG 预览，存放于文件头与正文之间（`SKETH` 信封，`THUMB_LEN = 0` 表示无预览），正文因此保持与原文件逐字节一致。Web 端通过 `/ske-thumb` 只解密这枚信封（约 40 KB），列表无需为此拉取 1 MiB 密文块，也无需为视频解码首帧。图片由 Pillow 缩放；视频抽帧优先用 PyAV（`pip install .[video]`，自带解码器），未安装时回退系统 ffmpeg，两者都没有则跳过（加解密不受影响）；Web 端加密视频时由浏览器抓帧。源文件已足够小、或预览成本超过源文件 1/4 时同样跳过。

### 文件名加密
文件名同样被加密：使用固定盐派生的密钥与从密钥派生的固定 IV 进行**确定性** AES-GCM 加密，因此相同明文文件名始终得到相同密文 token，无需数据库即可在云端重建整棵目录树。

### 网络优化
最新的 SW 2.0 架构引入了 **Session 级缓存**，对于同一次播放，文件头和导出密钥只需计算/拉取一次。针对视频拖动，SW 会通过 `inflight` 合并重复请求，避免了带宽浪费。

### 安卓端实现
安卓客户端复用完全相同的 `.ske` 版本 001 格式（字节级兼容，见 `ske_android/app/src/test`）。播放时通过 Media3 自定义 `DataSource` 按需拉取密文块——远端走 HTTP Range、本地走 SAF 随机读——在内存中解密后喂给播放器，因此拖动进度条时只会下载所覆盖的块。已解密的块由内存 LRU 复用；另有可选的两层磁盘缓存：缩略图（默认开启，128 MB）与解密后的媒体块（默认关闭，1 GB），写在应用私有的 `cache/` 目录，超出上限按最久未用淘汰，锁定、关闭开关或系统清理缓存时清空。

### 安卓内置服务器（`openlist` 变体）
内置服务器走的是另一条路：`openlist-lib/build.ps1` 用 gomobile 把 OpenList（默认 v4.2.9）编成 AAR，运行时在应用进程内启动，只监听回环地址，配置与数据放在应用私有目录，同一网络里的其他设备看不到它；保活靠前台 `dataSync` 服务，Android 15 的超时会连带停掉服务，下次打开应用重新拉起。

### 桌面端实现
桌面端把 Electron 主进程当作唯一能接触磁盘与网盘的一侧，渲染进程只通过 IPC 请求目录列表、缩略图与媒体流，密码不出主进程。

- **本地库**：主进程用 `fs` 直接读写用户选定的目录，加密文件名解密后随列表返回。相比浏览器的 File System Access API，重启后不需要重新授权，路径也稳定。
- **播放**：媒体路由把本地 `.ske` 或远端加密文件统一成明文字节流，再由 `127.0.0.1` 上一个随机端口的 HTTP 服务输出；每个请求都必须携带本次启动才有效的 token，避免同机其他进程读取解密内容。Chromium 因此能以与网站完全一致的方式处理 `Range` 与 `<video>`，Web 端的解密管线可以原样复用。播放窗口（视频、音乐、侧栏音乐条）和两个文件库里任意媒体文件的右键菜单都能一键复制这条带 token 的地址，粘进 mpv / VLC / PotPlayer 即可播放并自由拖动进度，明文始终不落盘；链接只在本机有效，应用退出、停止播放或复制另一条链接后失效。右键里还有「外部播放器」，展开的二级菜单会列出本机找到的 mpv / VLC / PotPlayer / MPC，选哪个就用哪个打开同一地址 —— avi、wmv、flv、ts 这类内置播放器打不开的容器因此也能看。查找覆盖常见安装布局、程序目录扫描与 Windows 的 shell 注册信息，所以装在 D 盘或绿色目录同样能找到；也可以在「设置 → 播放」里固定默认播放器。
- **拖放上传**：把文件拖进云端库窗口就能上传，落到哪个文件夹就传到哪个文件夹，随后与点「上传」选文件走同一条确认流程（可选是否加密）；文件夹不会被递归展开，会被跳过并提示。
- **加密预览**：加密媒体时一定会写入那枚 512px 预览 —— 图片等比缩放、视频在 30% 处抽帧，与 CLI / 安卓端的规则一致。`ffmpeg` 与 `ffprobe` 随应用打包（`ffmpeg-static` + `@ffprobe-installer/ffprobe`，解包在 `app.asar.unpacked` 下直接调用），用户无需自行安装；工具缺失时任务会明确报错，而不是产出一个永远没有封面的容器。只有源文件本身太小、或预览成本超过源文件 1/4 时才跳过。
- **系统媒体控制**：音频只在壳窗口播放，因此全应用只有一个渲染进程发布 Media Session —— Windows 的 SMTC、macOS 的 Now Playing 与 Linux 的 MPRIS 会直接显示曲名、封面，并接管播放 / 上一首 / 下一首 / 进度，不需要任何原生模块；锁屏或停止播放时清空，避免在系统面板或锁屏上留下歌名。
- **启动锁**：密码以 `scrypt`（每次安装独立 salt）保存；TOTP 密钥改用 `safeStorage`（Windows DPAPI / macOS Keychain / libsecret）密封，因为「任一通过」意味着在校验验证码时还拿不到密码。
- **缓存**：缩略图会把容器里那枚 512px 加密预览按媒体密码派生的密钥重新加密后落盘，可设容量上限并按最久未用淘汰；解密块与签名下载地址只留在内存，退出即释放。
- **后端**：AList 与 OpenList 共用同一套请求层，OpenList 只补上 `/api/fs/multipart/*` 分片上传（init → 分块 → complete），大文件走它；服务端不支持时自动退回单次上传。
